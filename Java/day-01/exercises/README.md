# Day 1 Exercises

Create your solutions in this folder.

## Required files

- `EmployeeProfile.java`
- `SubscriptionBilling.java`
- `answers.md`

## How to compile and run

From this directory:

```bash
javac EmployeeProfile.java
java EmployeeProfile

javac SubscriptionBilling.java
java SubscriptionBilling
```

## Submission checklist

- [ ] Both programs compile without errors.
- [ ] Output is correctly labelled and readable.
- [ ] Variable names are meaningful.
- [ ] Answers are written in your own words.
- [ ] Commit your work to GitHub.

When ready, share the commit link or paste the code in the learning conversation for review.
