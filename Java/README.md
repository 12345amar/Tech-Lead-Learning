# Java Full Stack Tech Lead Learning Track

A practical, 2-hour-per-day learning path designed to build from basic Java knowledge toward Java Full Stack Tech Lead capability.

## Learner profile
- Current Java level: Basic
- IDE: Visual Studio Code
- Daily commitment: 2 hours
- Goal: Java Full Stack Developer + Tech Lead
- Learning approach: concepts, hands-on coding, exercises, assessments, code reviews and architecture discussions

## Roadmap

| Phase | Topics | Outcome |
|---|---|---|
| 1. Java foundations | JDK/JRE/JVM, syntax, types, operators, control flow, methods | Write and explain core Java programs |
| 2. Object-oriented Java | Classes, objects, constructors, encapsulation, inheritance, polymorphism, abstraction, interfaces | Design maintainable domain models |
| 3. Core APIs | Strings, arrays, exceptions, collections, generics, date/time, streams, lambdas, Optional | Write idiomatic Java |
| 4. Advanced Java | JVM memory, garbage collection, concurrency, threads, executors, synchronization | Reason about performance and concurrency |
| 5. Build and testing | Maven, Git, JUnit, Mockito, logging, debugging | Build and test production-quality code |
| 6. Spring ecosystem | Spring Core, dependency injection, Spring Boot, REST, validation, configuration, security | Build secure backend services |
| 7. Data and persistence | SQL, MySQL, JDBC, JPA, Hibernate, transactions, indexing | Design reliable persistence |
| 8. Distributed systems | Microservices, Kafka, Redis, resilience, observability, API design | Design scalable services |
| 9. Full stack integration | React integration, authentication, authorization, API contracts | Deliver end-to-end features |
| 10. Delivery and cloud | Docker, Kubernetes, CI/CD, cloud deployment, monitoring | Operate services reliably |
| 11. Tech Lead readiness | System design, architecture, code reviews, mentoring, technical decisions | Lead delivery and technical direction |

## Daily study format (120 minutes)
1. Concepts and explanations — 25 minutes
2. Code walkthrough — 20 minutes
3. Hands-on coding — 45 minutes
4. Exercises — 20 minutes
5. Assessment and progress update — 10 minutes

## Suggested project
Build a Telecom Subscription Management Platform:
- Java and Spring Boot backend
- React frontend
- MySQL database
- REST APIs and validation
- Spring Security and JWT
- Redis caching
- Kafka-based asynchronous events
- Docker and Kubernetes
- CI/CD and monitoring

The project will evolve as each relevant topic is learned. Do not introduce tools before their prerequisite concepts are covered.

## How progress is tracked
For every study day:
- Review the learner's submitted code and reasoning.
- Record exercises completed and feedback.
- Record assessment score when available.
- Identify gaps and assign targeted revision.
- Unlock the next day when the current day's learning objectives are demonstrated.
